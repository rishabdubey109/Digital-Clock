# Digital Clock

A simple real-time Digital Clock created using HTML, CSS, and JavaScript.  
It displays the current time and date and updates automatically every second.

## Features

- Displays current hours, minutes, and seconds
- 12-hour time format with AM/PM
- Shows the current date
- Updates automatically every second
- Simple and clean user interface
- Responsive design for mobile and desktop screens

## Technologies Used

- HTML
- CSS
- JavaScript

digital-clock/

## How It Works

JavaScript's `Date()` object is used to get the current system time.

The clock gets the current:
- Hours
- Minutes
- Seconds
- Date

The `setInterval()` function updates the clock every 1000 milliseconds (1 second).

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The digital clock will start automatically.


## Purpose of the Project

This project was created to practice the basic concepts of HTML, CSS, and JavaScript. It helped me understand how JavaScript can be used to work with real-time data and dynamically update content on a webpage.
